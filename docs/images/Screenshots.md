## How to generate screenshots

1. Start the dev server: `npm run dev` (or `vercel dev` for API routes).
2. Navigate to `http://localhost:5173`.
3. Use a browser screenshot tool (e.g., Chrome DevTools → three-dot menu → "Capture screenshot").
4. Save each file to `docs/images/`.
